THE PROJECT
-----------
01 — The project
What you see
is what you feel.
Enhanced Visuals Java Edition Shaders, better known as Crystaline, is a Minecraft shader project born from my curiosity about real-time graphics. It asks whether realism always has to be the goal, or whether a shader can be artistic without shouting for attention.
This is an ongoing personal project, built through experiments, tested in-game, and refined one rendering problem at a time. Performance is a requirement, not a bonus.

BEHIND THE IMAGE
----------------
04 — Behind the image
Looks are one thing.
Making them run is another.
Crystaline is built from scratch, not forked from an existing shader pack. It is a stubborn experiment in seeing how far rasterization can go, even on limited hardware. Real-time rendering demands care: a seemingly simple visual effect can bring performance to its knees if it is implemented without thought. Those constraints are exactly what Crystaline is built to explore.
For now, this site focuses on what I can show: the scenes above and the current work-in-progress build. More detailed technical notes will come with future releases.
